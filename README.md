# Macro Station — Client

[Macro Station](https://github.com/Deccoyi/macro-station) sisteminin telefon/tablet tarafı: Windows'ta çalışan Macro Station sunucusuna aynı yerel ağdan bağlanıp, sunucudaki editörle tasarlanan grid'i tam ekran, dokunmatik bir "deck" olarak gösteren Capacitor + React uygulaması.

Sunucu (arka uç + WebView2 editörü) ayrı bir repoda: **https://github.com/Deccoyi/macro-station**. İki repo bağımsız sürümlenir — bu repoya atılan bir düzeltme sunucunun sürümünü etkilemez ve tam tersi.

## Durum

**Erken aşama / MVP.** Şu an çalışan: sunucu IP'sini elle girip bağlanma, sunucudaki profilin sayfasını çizme, buton/toggle basış-bırakış-uzun basış-çift dokunuş olaylarını sunucuya iletme, bağlantı koptuğunda otomatik yeniden bağlanma (exponential backoff).

**Henüz yok:** mDNS/QR/PIN ile otomatik eşleştirme, profil seçim çekmecesi (drawer), kiosk modu, ekranı uyanık tutma (keep-awake) entegrasyonu, offline/son-layout önbelleği, slider/knob'un gerçek çift yönlü değer akışı.

Ayrıntılı yol haritası için sunucu repo'sundaki [docs/plan.md](docs/plan.md)'ye bakın (Aşama 5 bu repoyu kapsar).

## Gereksinimler

- Node.js 20+
- Android'e derlemek için: Android Studio + SDK, `JAVA_HOME`/`ANDROID_HOME` ortam değişkenleri

## Çalıştırma

```bash
npm install

# Tarayıcıda geliştirme (sunucu IP'sini uygulama içinden gireceksiniz)
npm run dev

# Web build + Android senkronizasyonu
npm run build
npx cap sync android
npx cap open android   # Android Studio'da açar
```
