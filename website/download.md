# Download for Android

<DownloadList />

::: warning Alpha software, install at your own risk
The Macro Grid phone app is alpha software written entirely by an AI assistant and not security-audited. The release workflow builds the APK with the project's release key only when the maintainer has configured signing secrets. Otherwise it builds a **debug-signed APK** (the file name ends in `-debug.apk`): it installs on a phone, but it is not a real release build and cannot be updated by a later release-signed build. In that case you would have to uninstall the app before installing a signed one. Releases are first created as drafts and published by hand.
:::
